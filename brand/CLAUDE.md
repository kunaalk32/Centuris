# Centuris Capital brand (read before any UI, copy or marketing work)

- Brand book: `brand/README.md` (voice, colour rules, type, layout, section rhythm). Follow it.
- Tokens: `brand/tokens.css` (CSS variables; light is default, `[data-theme="dark"]` for dark). `brand/tokens.json` is the source.
- Logos: `brand/logos/`. Use `centuris-wordmark-on-dark.svg` on Ink Black, `-on-light.svg` on ivory. Never retype the wordmark in a font.
- Font: Geist only (Google Fonts, weights 300/400/500). NEVER add, upload or reference Michelangelus font files: its licence forbids web distribution. It exists only inside the logo SVGs.
- Text colours: only the pairings in the brand book's colour table. Camel (#B4925E) is never text on ivory; use camel-text (#6E5530).
- No eyebrows or overline labels, and headlines never end in a period. Don't call the firm "senior-secured": BPMOF holds subordinate B notes, so say "first lien" for the loans and state each fund's position.
- Motion: section overlap and image parallax (GSAP ScrollTrigger, Lenis), plus a one-time count up on the hero figures. Other figures and tables never animate.
- The website does not mention the former name.
- Performance figures need period, net/gross basis and a disclosure link. Marketing copy goes to counsel before launch.
