# Logos

Both wordmarks are outlined vector paths (no font file inside), so they are safe to use on the website, in ads and in documents.

- `centuris-wordmark-on-dark.svg`: CENTURIS in ivory (#F6F3EC), CAPITAL in camel (#B4925E). Use on Ink Black (#011627) or other dark grounds.
- `centuris-wordmark-on-light.svg`: CENTURIS in Ink Black (#011627), CAPITAL in camel-text (#6E5530). Use on ivory (#F6F3EC / #ECE6DA), sand or white.

The artboard is cropped tight to the letters. Add clear space equal to the height of the C (the full height of the mark) on every side. Minimum width: 140px on screen, 35mm in print; below that CAPITAL becomes hard to read. Never recolour, stretch, add effects or retype the mark.
